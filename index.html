    Before you build

    Use game backups and keys you have the right to use. Select both files together, or add them one at a time.

    The IPA is unsigned. Signing and installation happen separately. Creating an archive does not verify device compatibility or gameplay.

    Game archives are read in chunks. Extracted game data is currently limited to 256 MiB, so larger titles may not build. Extraction checks consistency, not publisher authenticity.

    Your files stay in this page's memory. Keys are released when a build finishes or is cancelled. Closing the page clears the session.
